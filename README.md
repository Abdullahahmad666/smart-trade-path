# Smart Trade Path — Forex Course Landing Page

Landing page for a Forex trading course focused on risk management and passing prop-firm (funded account) challenges.

## Sections
- Hero with Enroll and WhatsApp contact buttons
- What you'll learn and why choose this course
- Seven-module curriculum: Forex basics, market structure, indicators, smart money concepts, volume spread analysis, liquidity, and risk management
- Pricing, gallery and contact

## Tech stack
React · TypeScript · Vite · Tailwind CSS · shadcn/ui

## Run locally
```bash
git clone https://github.com/Abdullahahmad666/smart-trade-path.git
cd smart-trade-path
npm install
npm run dev
```
